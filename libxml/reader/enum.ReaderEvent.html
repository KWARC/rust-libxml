Expand description

The reader’s own event vocabulary (xmlReaderTypes), exposed losslessly.

TextReader::node_type maps events 1..=12 onto NodeType and everything else to None — which conflates end-element with the two whitespace events (13/14). A streaming caller that reconstructs document structure needs all three distinguished; TextReader::event returns this enum instead.
